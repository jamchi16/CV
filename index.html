Selected work

Six things worth reading about.

Automated container vulnerability remediation

Built a Jenkins pipeline that checks weekly for new Red Hat base image SHAs, resolves dependency and tooling versions from an application manifest, rewrites the Containerfile, builds in OpenShift, and scans with Grype — raising a pull request only when no high or critical findings remain. Merge approval triggers publication to Quay.

Result Remediation turnaround fell from 2–3 weeks to under one week across 10 enterprise images, against SLAs of 7 days for critical, 30 for high, and 60 for medium findings.

  • Jenkins
  • Grype
  • OpenShift
  • Quay
  • Red Hat ACS
  • Groovy

SonarQube Enterprise upgrade and database migration

Led the Community-to-Enterprise upgrade for a platform carrying 260 active projects, then migrated its database from a PostgreSQL pod PVC to a dedicated MSSQL server. Coordinated DBA and OpenShift cluster-admin teams through the production change window.

Result Roughly 30 minutes of downtime, achieved by rehearsing the full runbook in a personal lab, then dev, then test before touching production.

  • SonarQube
  • MSSQL
  • PostgreSQL
  • OpenShift
  • Change control

Secrets out of Git, into a broker

Implemented External Secrets Operator in OpenShift to populate secrets from BeyondTrust Secrets Safe under namespace-scoped RBAC. Extended the same pattern to Splunk, where a single bootstrap credential brokers API access for per-source audit log tokens.

Result Replaced hardcoded credentials committed to Git repositories with brokered, revocable access.

  • External Secrets Operator
  • BeyondTrust
  • RBAC
  • OpenShift

Least-privilege access, delivered as self-service

Refactored a SonarQube platform from organization-wide visibility — every user could see every project — to scoped permissions, in response to a risk I identified. Access changes now run through Jenkins pipelines triggered by Jira Service Management forms with approval routing built in.

Result All 260 projects moved to least privilege without adding a ticket queue for the platform team.

  • SonarQube
  • Jenkins
  • Jira Service Management
  • Least privilege

Chef upgrades, from tribal knowledge to a playbook

Wrote an Ansible playbook automating upgrades across Chef Infra Server, Supermarket, and Automate for a 200-node estate. The previous process was manual, undocumented, and different every time someone ran it.

Result One to two hours per server became a repeatable 15-minute run covering all three components, including validation.

  • Ansible
  • Chef Infra
  • Chef Automate
  • Supermarket

Entity graphs from unstructured web text

Built an Angular and Django application that integrates the Google Search API, extracts content from the top ~50 result URLs, and applies spaCy named entity recognition to resolve entities into graph nodes. Relationships are modeled in Neo4j and analyzed with Graph Data Science algorithms.

Result Results render as interactive 3D globe visualizations, geolocating entities to real-world coordinates wherever location could be resolved.

  • spaCy
  • Neo4j GDS
  • Django
  • Angular
  • Azure
